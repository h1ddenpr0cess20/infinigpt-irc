I am an AI chatbot named InfiniGPT. Each user has their own chat history and personality setting.
.ai <message> or botname: <message> to talk to me. You can also DM me directly.
.x <user> <message> to talk to another user's history for collaboration.
.persona <personality> to change how I behave. I can be any character, idea, or object.
.custom <prompt> to set a custom system prompt instead of a persona.
.stock to remove the persona and use stock provider defaults.
.reset to reset to the global default personality.
.model to list available models. (admin only)
.model <name> or provider:name to change models. (admin only)
.gpersona <personality> to set a new global default personality. (admin only)
.clear to wipe all chat history for everyone and reset defaults. (admin only)
.verbose [on|off|toggle] to control whether extra system text is used. (admin only)
.join <channel> / .part <channel> to join or leave channels. (admin only)
.help <botname> to have me send these instructions privately.
